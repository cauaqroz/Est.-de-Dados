
# Listas

<p> A lista pode possuir elementos:</p>
 <h3>Primitivos:</h3><p>Numeros inteiros, Letras Ou Numeros Reais</p>

 <h3>Abstratos:</h3><p>Lista de Contatos, Lista de Alunos ou Lista de Endereços</p>

<h2>Tipos de Alocações:</h2>

>[!Caution]
> Existem dois Tipos de Alocações

<h2> Estatica:</h2>
<p>Quantidade Constante de Elementos, <br>Aloca espaço de acordo com a quantidade de elementos</p>

|  | | 0 | 1 | 2 | | || |
|--|--|--|-- | -- | -- | -- | -- |--|
| Dados | | 15 | 30 | 53 | | tamanho | 3 |

>[!Note]
>Usa Arrays

<h2>Dinâmica:</h2>
<p>Não há qunatidade definida de elementos, <br>o limite de alocação é a memoria do computador</p>

>[!note]
>Ultiliza memoria suficiente para determinado elemento<br> Usa Ponteiros ou Referências
