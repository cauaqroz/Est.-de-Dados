<h2> - - Pilha - -</h2>

>[!WARNING]
> Topo da pilha é Igual ao indice <br>Do ultimo elemento adicionado


>Pilha Vazia Topo é igual a "-1"

| - | - | pilha | P1: | | |
| -- | -- | --- | --- | --- | ---|
| 2 | | dados |  |  |  |
| 1 | | indice | 0 | 1 | 2 |
| 0 | | topo | = | -1 |  |

#
>[!note]
>Adiciona 5

| - | - | pilha | P1: | | |
| -- | -- | --- | --- | --- | ---|

| 0 | 5 | topo | = | 0 |  |

#

>Adiciona 18

<h2> - - Fila - - </h2>

>[!Warning]
>O tamanho da fila é igual ao total de indices ocupados <br>Adicionar elemento: Tamanho = Tamanho + 1 <br>Remover elemento: Tamanho = Tamanho - 1 

>[!Note]
>Caso - Inicio da Fila <br>Caso - Remove 5

>Fila vazia Tamanho é Igual a 0

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados |  |  | |
| indice | 0 | 1 | 2 |
| tamanho | = | 0 |  |


#
>[!Note]
>Caso - Adiciona 5 <br>Caso - Remove 18

>Resultado:

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados | 5 | |  |
| indice | 0 | 1 | 2 |
| tamanho | = | 1 |  |

#
>[!Note]
>Caso - Adiciona 18 <br>Caso- Remove 4

>Resultado:

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados | 5 | 18 |  |
| indice | 0 | 1 | 2 |
| tamanho | = | 2 |  |

#
>[!Note]
>Caso - Adiciona 4

>Resultado:

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados | 5 | 18 | 4 |
| indice | 0 | 1 | 2 |
| tamanho | = | 3 |  |
