<h2> - - Fila - - </h2>

>[!Warning]
>O tamanho da fila é igual ao total de indices ocupados <br>Adicionar elemento: Tamanho = Tamanho + 1 <br>Remover elemento: Tamanho = Tamanho - 1 

>[!Note]
>Caso - Inicio da Fila <br>Caso - Remove 5

>Fila vazia Tamanho é Igual a 0

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados |  |  | |
| indice | 0 | 1 | 2 |
| tamanho | = | 0 |  |


#
>[!Note]
>Caso - Adiciona 5 <br>Caso - Remove 18

>Resultado:

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados | 5 | |  |
| indice | 0 | 1 | 2 |
| tamanho | = | 1 |  |

#
>[!Note]
>Caso - Adiciona 18 <br>Caso- Remove 4

>Resultado:

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados | 5 | 18 |  |
| indice | 0 | 1 | 2 |
| tamanho | = | 2 |  |

#
>[!Note]
>Caso - Adiciona 4

>Resultado:

| Fila | F1: | | |
| --- | --- | --- | ---|
| dados | 5 | 18 | 4 |
| indice | 0 | 1 | 2 |
| tamanho | = | 3 |  |
