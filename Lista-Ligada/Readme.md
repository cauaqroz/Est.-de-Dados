
<h1>- - Lista Ligada - -</h1>

>[!note]
>Nesta representação, cada [valor| ] é um nó da lista ligada. <br>O valor é o dado armazenado no nó, e a seta representa o link para o próximo nó.<br> O último nó da lista é ligado a NULL, indicando o fim da lista

<br>
<br>


| 1 | --> | 2 | --> | 3 | Null |
| -- | -- | --- | --- | --- | ---|

#
<h2>Estudo Prova</h2>
<p>implemente um método que recebe por parâmetro um elemento que deve ser removido <br> de uma lista ligadaque está organizada com os elementos em ordem crescente. <br> Após a remoção, se o elemento for encontrado e removido, o método deve retornar true. <br> E se o elemento não for encontrado, o método deve retornar false.
