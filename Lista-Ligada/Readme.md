
<h1>- - Lista Ligada - -</h1>

>[!note]
>Nesta representação, cada [valor| ] é um nó da lista ligada. <br>O valor é o dado armazenado no nó, e a seta representa o link para o próximo nó.<br> O último nó da lista é ligado a NULL, indicando o fim da lista

<br>
<br>


| 1 | --> | 2 | --> | 3 | Null |
| -- | -- | --- | --- | --- | ---|
