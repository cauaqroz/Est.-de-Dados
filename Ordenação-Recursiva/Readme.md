# Ordenação Recursiva
<P>O algoritmo de ordenação recursiva funciona dividindo a lista de elementos em duas partes menores, <br>ordenando cada parte recursivamente</P>

## MergeSort
<h4>merge sort</h4>
<p> é um algoritmo de ordenação que funciona dividindo uma lista em duas metades, ordenando cada metade recursivamente e, <br>em seguida, combinando as duas metades ordenadas em uma única lista ordenada. <br>O processo de divisão e conquista é repetido até que a lista esteja completamente ordenada.<br> O merge sort é um algoritmo de ordenação eficiente que tem uma complexidade de tempo de O(n log n) e é frequentemente usado para ordenar grandes conjuntos de dados</p>


## QuickSort

<h4>Quick Sort</h4>
<p>O algoritmo escolhe um elemento como pivô e particiona o array em dois subarrays, de forma que os elementos menores que o pivô fiquem à sua esquerda e os maiores à direita.<br> Em seguida, o algoritmo ordena recursivamente os subarrays à esquerda e à direita do pivô. <br>O processo é repetido até que a lista esteja completamente ordenada. <br>O Quick Sort é um algoritmo de ordenação eficiente e tem uma complexidade de tempo médio de O(n log n)</p>
