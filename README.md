## Resumo Fila e Pilha

<h4>- Pilha -</h4>
<P>Pilha em Java Segue o Principio LIFO, <br>ou seja
o ultimo elemento a ser inserido é o primeiro a ser retirado</P>

<h4>- Fila -</h4>
<P>Fila em Java Segue o Principio FIFO, <br> ou seja o primeiro elemento que entra é o primeiro a sair</P>

>[!Note]
>LIFO: Last In First Out<br>
>FIFO: First In First Out
